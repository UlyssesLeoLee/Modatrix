# Third-party notices

FrameForge 3D project code is licensed under MIT. Third-party dependencies retain
their own licenses and notices; the project license does not relicense them.

The source baseline requires permissive licenses for direct and transitive
dependencies. Verify the complete resolved dependency graph with `cargo deny`
and a Python SBOM/license scanner before release. No model weights, fonts,
textures, sample meshes, or proprietary assets are bundled. A model's license is
independent of the license of the runtime used to load it.
