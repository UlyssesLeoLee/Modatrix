# MODATRIX

**AI-Powered 3D Review & Revision**

> From Feedback to Reality.  
> 让每一条反馈，成为真正的修改。

MODATRIX 是一款面向 3D 模型与动画制作的 AI 驱动审查及修改工具，将可视化反馈、智能编辑与版本管理整合为统一工作流。

## ✨ 核心功能

- **Visual Review** — 基于时间轴与审查快照，对 3D 模型和动画进行精准批注。
- **AI Revision** — 根据自然语言反馈，辅助修改模型、骨骼、蒙皮权重及动画。
- **Motion Editing** — 智能分析并调整动作、姿态和关键帧。
- **Version Tracking** — 修改前后差异对比、历史追溯与回退。
- **Agent Workflow** — 基于 LangGraph 编排多 Agent 审查、修改与验证流程。
- **Extensible API** — 支持自定义 AI 模型、API 与插件扩展。
